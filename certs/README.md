# Доверенные сертификаты

Сюда положите корневой сертификат Минцифры — без него не установится
TLS-соединение с `platform-api2.max.ru` (раздел 2 ТЗ). Скачать: раздел
«Сертификат для ПК» на https://www.gosuslugi.ru/crt

**Клиент подхватывает всё, что лежит здесь с расширением `.crt`,
самостоятельно** — ни переменных окружения, ни установки в систему не
нужно. Системные удостоверяющие центры при этом сохраняются: вложения
раздаются с обычного CDN, и заменить весь набор одним корнем значило бы
починить API, сломав скачивание файлов.

`update-ca-certificates` в образе подхватывает только файлы с расширением
`.crt` в формате PEM. Скачанный `russian_trusted_root_ca.cer` переименуйте
в `russian_trusted_root_ca.crt`. Если файл в формате DER — сконвертируйте:

```bash
openssl x509 -inform der -in russian_trusted_root_ca.cer -out russian_trusted_root_ca.crt
```

Проверить, что сертификат подхватился, можно из контейнера:

```bash
docker compose run --rm api python -m repairbot.cli bot-info
```
